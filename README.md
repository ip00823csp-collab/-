# ☀️ 心晴 - 温暖的陪伴

> 专为残障长辈设计的心理疗愈与温暖陪伴应用

## 💛 产品理念

每一位长辈都值得被温柔以待。「心晴」是一款面向残障老人的心理疗愈陪伴应用，通过简洁温暖的交互、贴心的语音功能、舒缓的音乐和呼吸引导，帮助长辈们在日常生活中感受到关怀与陪伴。

### 🌅 真实使用场景

张奶奶，78岁，中风后右半身不便，子女在外地工作。每天大部分时间独坐家中。

- **清晨**，她打开应用，小暖温暖地问好："早上好呀，张奶奶！今天阳光很好，陪您聊聊天吧？"
- **午后**，有些困倦，她跟着小暖做几个深呼吸，身心慢慢放松
- **傍晚**，有些孤单，她跟小暖聊天，说说心里话，小暖温柔地回应
- **睡前**，她翻看孙子的照片，听着大自然的声音，带着微笑入眠

## ✨ 核心功能

| 功能 | 描述 |
|------|------|
| 🏠 温暖问候 | 根据时间、姓名，给予个性化温暖问候 |
| 😊 心情签到 | 简单5个表情，记录每日心情，给予贴心回应 |
| 💬 聊天陪伴 | 智能语音输入，温暖贴心的对话回应 |
| 🎵 舒缓音乐 | 雨声、鸟鸣、溪流等自然声音，帮助放松 |
| 🌿 呼吸放松 | 引导式深呼吸练习，简单直观的动画指引 |
| 📷 美好回忆 | 照片墙，翻看美好记忆，带来温暖感受 |
| 📞 紧急呼叫 | 一键呼叫家人，安全感满满 |

## 🎨 设计原则

- **温暖**：暖色调UI、柔和动画、贴心语言
- **简单**：大按钮、大字体、一键操作、语音输入
- **关怀**：每个交互都传递关心和支持
- **安全**：紧急呼叫功能，让家人放心

## 🛠 技术栈

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Web Audio API (自然声音生成)
- Web Speech API (语音输入)
- LocalStorage (本地数据存储)

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 📱 使用方式

1. 打开应用，输入您的名字
2. 小暖会根据时间向您问好
3. 选择今日心情，获得贴心回应
4. 和小暖聊天、听音乐、做呼吸练习
5. 在设置中添加紧急联系人号码
